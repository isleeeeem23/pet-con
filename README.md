> **PetConnect** is a modern, end-to-end web platform designed to streamline pet adoption by connecting adopters directly with rescuers and shelters. Featuring AI-assisted photo verification, interactive location mapping, and real-time messaging.

---

## ✨ Key Features

- 📸 **AI Photo Verification:** Uses **MobileNet** machine learning model to verify and validate pet image listings automatically.
- 🗺️ **Interactive Location Mapping:** Integrated **Leaflet.js** map system allowing users to search and discover adoptable pets nearby.
- 💬 **Real-Time Communication:** Built-in **AJAX** direct messaging interface between adopters and pet owners.
- 🔐 **Secure Authentication:** Complete user management system built with PHP PDO and MySQL.
- 📱 **Responsive UI:** Clean, modern interface designed with a dark/slate aesthetic for intuitive navigation.

---

## 🛠️ Tech Stack

- **Backend:** PHP 8, MySQL (PDO)
- **Frontend:** HTML5, CSS3 (Glassmorphism design), JavaScript (ES6+), AJAX
- **AI/ML:** MobileNet Model (Pet Image Classification)
- **Mapping:** Leaflet.js
- **Version Control:** Git & GitHub

---
